# PraiseView

Modern JavaFX alternative to OpenLP for church projection.

## How to Run

1. `mvn clean javafx:run`

## How to Package

`mvn clean package`

Then use jpackage for native installers.

## Features Implemented
- Multi-monitor projection support
- Dark theme
- Song + Verse model with Chorus/Coda support
- Basic projection controller

More features coming soon!
