== Welcome! 👋

== Installation & Setup

=== System Requirements

Before installing, ensure you have:
- **2GB RAM minimum** (4GB recommended for media-heavy services)
- **Screen resolution 1920x1080 or higher** (recommended)
- **Windows 10 or later** (Windows 11 preferred)
- **500MB free disk space**

=== Download and Install

1. **Download** PraiseView installer (praiseview.msi) from official website
2. **Run the installer** - Double-click praiseview.msi
3. **Security prompt** - Click "Run Anyway" if Windows shows a warning
4. **Wait for installation** - Takes 1-2 minutes
5. **Launch application** - Search for "PraiseView" in Start Menu

=== First Launch

When you open PraiseView for the first time, it will:
- ✅ Check for the latest updates
- ✅ Create a database for your content
- ✅ Initialize default themes
- ✅ Set up the projection screen (if connected)

[TIP]
PraiseView detects a projector connected before or after the app starts. The status light beside **Stage View** is green when a second display is available and red when it is not.

== 🚀 Creating Your First Service (5 minutes)

Let's create a simple service with one song. Follow these steps exactly:

=== Step 1: Create Your First Song

1. **Bottom left** - Click the **Songs** tab (if not already selected)
2. **Add button** - Click **➕ Add New Song**
3. **Song Editor Wizard Opens** with 4 steps:

====== Step 1: Basic Information
   - **Title**: "Amazing Grace" (or your favorite song)
   - **Language**: English
   - **Categories**: "Hymns" (select or type a new category)
   - Click **Next →**

====== Step 2: Add Verses
   - Click **Add Verse** button for each verse
   - Select verse type (Verse, Chorus, Bridge, etc.)
   - Paste or type the verse text
   - Repeat until all verses/chorus are added
   - Click **Next →**

====== Step 3: Performance Order
   - Drag verses to arrange display order
   - Example: Verse 1 → Chorus → Verse 2 → Chorus → Verse 3
   - Use buttons to add, remove, or reorder
   - Click **Next →**

====== Step 4: Confirmation
   - Review all details (Title, Language, Categories, Verses, Order)
   - Click **Finish** to save the song

image::../images/asidocs/song-editor.png[Song Editor Wizard, align=center]

[NOTE]
The Performance Order determines which verses display during projection. Arrange them in your preferred sequence.

=== Step 2: Add Song to Service

1. **Find your song** - Look for "Amazing Grace" in the Songs tab
2. **Drag to service** - Drag it to the left panel (Service Planner)
3. **Confirmation** - You should see it appear in the service list on the left

=== Step 3: Project Your First Item

1. **Select the song** - Click on "Amazing Grace" in the left panel
2. **Center preview** - Notice the center panel shows the first verse
3. **Click Project** - Click the **Project** button at the top
4. **Look at your projection screen** - You should see the song verse displayed!

Congratulations! You've projected your first item. 🎉

=== Step 4: Navigate Through Verses

Try these controls:
- **Next ▶** button - Move to next verse
- **Previous ◀** button - Go back to previous verse
- **Arrow keys** - Keyboard alternative (← and →)
- **Left click on verse** - Jump directly to a specific verse (shown in center panel)

[TIP]
The stage view (center panel) is your "safe" preview. Always check it before clicking Project.

== Building Your Content Library

Now let's expand beyond one song:

=== Add More Songs

Repeat Step 1 for each song you want to add:
1. Click ➕ Add New Song
2. Fill in title, category, language
3. Add verses
4. Set performance order
5. Save

[TIP]
**Pro tip**: Create consistent categories like "Entrance", "Worship", "Prayer Songs", "Recessional" to organize better.

=== Import Songs from JSON (Optional)

If you have a JSON file with multiple songs:

1. **File > Import Songs**
2. **Choose filter** - Select "All Files (*.*)" if you can't see your .json file
3. **Select file** - Pick your JSON file
4. **Wait** - Songs are added to library
5. **Verify** - Check Songs tab to see imported songs

[NOTE]
Import is useful for copying songs from another PraiseView installation or from a church songbook provider.

=== Add Prayers

Similar to songs:

1. Click **Prayers** tab
2. Click ➕ **Add New Prayer**
3. Enter prayer title
4. Enter prayer text
5. **Optional - Add Slides**: Click "+ New Slide" to split prayer into multiple slides
   - Inserts `[==slide==]` marker at cursor position
   - During projection, content displays as separate slides
6. Click **Save**

Prayers can be any length—they'll automatically break into multiple slides if needed.

=== Add Images

For visual worship elements:

1. Click **Images** tab
2. Click 📁 **Open Images**
3. Select image files from your computer
4. **Auto-import** - Images appear in Images tab
5. **Drag to service** - Add to your service order

[TIP]
Use high-quality images (1920x1080 or higher) for best projection results.

=== Add Videos

For multimedia content:

1. Click **Videos** tab
2. Click 🎬 **Open Videos**
3. Select video files (MP4, WMV, AVI)
4. **Auto-import** - Videos appear in Videos tab
5. **Drag to service** - Add to your service order
6. **Double-click to play** - During service, double-click a video in the Service Planner to start playback

[CAUTION]
Test videos before service! Large files may take time to load.

== Organizing with Categories

PraiseView includes a powerful category system for songs:

=== Filter by Category

1. Go to **Songs** tab
2. **Left panel** - You'll see a category list
3. **Click a category** - Shows only songs in that category
4. **[All Songs]** - Click to show all songs again

=== Create Categories

When adding a song, enter any category name you want:
- "Contemporary"
- "Hymns"
- "Christmas"
- "Easter"
- "Children's Songs"
- Your custom names!

[TIP]
Songs with no category appear as "Others". Use categories consistently to stay organized.

== Customizing with Themes

Make your projection visually appealing with the new theme editor wizard:

=== View Default Themes

1. **Right panel** - Shows available themes and dropdown
2. **Select from dropdown** - Choose a theme to apply
3. **Preview** - Changes appear in center panel immediately
4. **Apply** - Theme applies to current and future items

=== Create Your Own Theme

1. Click **+ Create New Theme** button
2. **Theme Editor Wizard Opens** with 4 steps:

==== Step 1: Background Selection
   - Choose type: **Color**, **Image**, or **Video**
   - Select/upload your background
   - See preview in real-time
   - Click **Next →**

==== Step 2: Main Text Settings
   - **Font family** - Choose typography
   - **Font size** - Adjust for readability
   - **Text color** - Select text color
   - **Line spacing** - Adjust spacing
   - See preview changes instantly
   - Click **Next →**

==== Step 3: Title Settings
   - **Title font** - Separate from main text
   - **Title size** - Make titles stand out
   - **Title color** - Choose distinct color
   - **Title alignment** - Left, center, or right
   - Click **Next →**

==== Step 4: Confirmation
   - **Full preview** - See complete theme
   - **Review all settings** - Verify customizations
   - Click **Finish** to save and apply theme

[TIP]
Use consistent themes throughout your service for a professional look.

=== Theme Title Display Options

In the Theme Editor, you can choose:

**Show Title on All Slides**::
  Title appears at the top of every verse slide. Good for unfamiliar songs.

**Show Title as First Slide**::
  Title appears only on the first slide, then verses display without title. More minimal look.

[NOTE]
These two options are mutually exclusive. Enable one at a time.

== Managing Your Service

=== The Service Planner (Left Panel)

This shows your worship order:
- **Double-click an item** - Start projecting from that point
- **Select an item** - Center panel shows preview
- **Drag to reorder** - Change the order
- **Right-click** - Delete or edit options
- **Keyboard shortcuts**:
  - Ctrl+Up - Move item up
  - Ctrl+Down - Move item down
  - Delete - Remove item

=== Adding Items to Service

Three ways to add items:

**Drag and Drop**::
  1. Find item in bottom tabs (Songs, Prayers, etc.)
  2. Drag it to the Service Planner on the left
  3. It's added to your service

**Double-Click**::
  1. Find item in bottom tabs
  2. Double-click to add to service

**Right-Click Menu**::
  1. Right-click item in bottom tabs
  2. Select "Add to Service"

=== Saving Your Service

Save your service to use again:

1. **File > Save Service**
2. **Choose location** - Pick where to save
3. **Name your service** - e.g., "Sunday Service 2025-01-12"
4. **Save** - Saved as .service file

=== Loading Your Service

Open a saved service:

1. **File > Load Service**
2. **Select file** - Choose your .service file
3. **Open** - All items and order are restored

[TIP]
Create services a day or two before your actual service. Gives you time to test and prepare.

== 📱 Phone Remote Control

Control your service from your smartphone—great for:
- Standing in different parts of the room
- Navigating without being tied to the computer
- Audience interaction

=== Quick Setup

1. **Click** **Help > Connect Phone** in menu bar
2. **Note the network address** shown in dialog
3. **Download app** - "PraiseView Companion" from Google Play Store
4. **Open app on phone** - Enter the network address
5. **Connect** - Both devices on same WiFi network

[TIP]
Use landscape orientation on your phone for better readability.

=== What You Can Do with Phone

- 📋 View service list
- 🎵 Select songs to project
- ▶️ Navigate to specific verses
- ⏯️ Control video playback
- 👁️ See what's currently displayed

== Common First-Time Mistakes

Avoid these common issues:

❌ **Forgetting to set Performance Order**::
  Songs won't project if verse order isn't set. Always drag verses into desired order.

❌ **Not previewing before projecting**::
  Always check the center (Stage View) panel before clicking Project.

✅ **Connecting a projection screen after starting PraiseView**::
  This is supported. PraiseView detects the new display, switches the live projection to it automatically, and keeps the current item visible.

❌ **Using very small fonts**::
  Remember: people in the back of the room need to read it. Use at least 40pt font.

❌ **Not saving services**::
  Save your service as .service file so you can reuse it. Don't just rely on memory!
