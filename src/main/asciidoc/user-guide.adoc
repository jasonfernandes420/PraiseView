== Introduction

This comprehensive guide covers all the essential features and workflows in PraiseView to help you manage and present content during worship services with confidence and ease.

== Interface Overview

[.ui-section]
*Main Application Layout*

The PraiseView interface is divided into four main areas:

image::../images/asidocs/interface-layout.jpg[Interface Layout, align=center]

- **Left Panel**: Service Order (Planner) - Your worship service sequence
- **Center Panel**: Stage View - Live preview of what's being projected
- **Right Panel**: Themes and Controls - Visual themes and display options
- **Bottom Panel**: Library Tabs - Access all your content (Songs, Prayers, Media, etc.)

== Creating a Service

=== New Service

To start a new service:

1. Click **File > New Service**
2. Clear the current service order and start fresh
3. Begin adding content from the library tabs

=== Save Service

Save your service for future use:

1. Click **File > Save Service**
2. Choose a location and filename
3. Your service will be saved in PraiseView format

To load a previously saved service, click **File > Load Service** and select the file.

== Managing Songs

=== Adding Songs

==== Add a New Song

1. Go to the **Songs** tab at the bottom
2. Click **➕ Add New Song**
3. Enter song details:
   - Title: Name of the song
   - Category: Group/category for organization
   - Language: Language the song is in
   - Verses: Add individual verses, chorus etc
4. Add the Available Verses to the Performance order
5. Click **Save**

==== Import Songs

To import songs from a JSON file:

1. Click **File > Import Songs**
2. Select your JSON file
3. Songs will be added to your library automatically

=== Filtering Songs by Category

The Songs tab now includes a category filter on the left side:

1. Click a category name to show only songs in that category
2. Search by typing in the search field - it will search titles and categories
3. Click **Clear Filter** to show all songs again

=== Editing Songs

1. Select a song from the library
2. Click **✎ Edit Selected**
3. You can Add new verses/chorus or Modify existing verses by selecting on the Available verses list and modifying in Edit/View Lyrics. Then Click on Update Verse.
4. Click **Save**

== Managing Prayers

=== Adding Prayers

1. Go to the **Prayers** tab
2. Click **➕ Add New Prayer**
3. Enter prayer details:
   - Title: Name/subject of the prayer
   - Content: The full prayer text
4. Click **Save**

=== Importing Prayers

1. Click **File > Import Prayers**
2. Select your JSON file (you can now see all files, not just .json)
3. Prayers will be added to your library

=== Using Prayers in Services

1. Drag prayers from the prayer library to the service order
2. Click to project a prayer
3. Use navigation buttons to go through content

== Service Order Management

The left panel shows your current **Service Order** - the sequence of items to present.

=== Adding Items to Service

Drag items from any library tab to the service order:

1. Click and hold on a song, prayer, or media item
2. Drag to the service order list
3. Release to place the item

=== Reordering Items

==== Using Buttons

1. Select an item in the service order
2. Click **▲ Up** or **▼ Down** to move it
3. Use multiple clicks to move items to the desired position

==== Using Keyboard

1. Select an item and press **Ctrl+Up** or **Ctrl+Down**

==== Using Drag & Drop

1. Click and drag an item within the service order list
2. Move it to the desired position

=== Deleting Items

1. Right-click an item in the service order
2. Click **Delete**
3. Or select an item and press **Delete**

== Projecting Content

=== Starting Projection

1. Select an item in the service order
2. Click **Project** button
3. Content appears on the projection screen

Or double-click an item to start from that point.

=== Navigation Controls

==== Verse/Page Navigation

- **Previous**: Go to previous verse or page
- **Next**: Go to next verse or page

==== Skipping verses
- Click on the verse number in the Current item Verses/Pages to skip to a specific verse.

==== Video Controls

- **⏪ -10s**: Rewind 10 seconds
- **⏯️ Play/Pause**: Toggle playback
- **⏩ +10s**: Forward 10 seconds

==== Screen Controls

- **Blackout**: Show black screen (with fade)
- **Clear**: Show logo or empty screen

== Multimedia

=== Images

1. Go to **Images** tab
2. Click **📂 Open Images**
3. Select image files to add
4. Drag the image to service pane and click on the image to project it

=== Videos

1. Go to **Videos** tab
2. Click **🎬 Open Videos**
3. Select video files
4. Use video controls to manage playback

=== Audio

1. Go to **Audio** tab
2. Click **🎵 Open Audio**
3. Select audio files
4. Play background music or special effects

=== PowerPoint Presentations

1. Go to **PPT** tab
2. Click **📊 Open PPTs**
3. Select .ppt or .pptx files
4. Navigate through slides using Previous/Next buttons

== Themes

=== Applying Themes

1. Go to the **Themes** tab on the right
2. Select a theme from the list
3. The theme background applies to all projections

=== Theme Options

- **Show Title on All Slides**: Show the title on every lyric slide
- **Show Title as First Slide**: Show the title only on the first slide
- These two options are mutually exclusive
- This setting is configured in **Themes > Theme Editor**

=== Creating Custom Themes

1. Click **Themes > Theme Editor**
2. Create a new theme or modify existing ones
3. Set background colors or images
4. Save your theme

== Phone Remote Control
Download the PraiseView Companion App from Google Play Store

=== Connecting Your Phone

1. Click **Help > Connect Phone**
2. Ensure both the Desktop and the Android Phone are on the same network.
    Alternatively, if your Desktop supports Wifi, start a mobile hotspot on the Phone and
    add the Desktop to the hotspot.
3. Scan the QR code from the Android Phone.
4. Connect to the local network with the provided address
5. Use your phone to control presentations

=== Phone Features

- View and select songs from your service
- Select specific verses to display
- Navigate through content
- Control playback

== Exporting Content

=== Export Songs

1. Click **File > Export Songs**
2. Select which languages to export
3. Choose save location
4. Songs are saved as JSON file

=== Export Prayers

1. Click **File > Export Prayers**
2. Choose save location
3. Prayers are saved as JSON file

== Troubleshooting

=== Common Issues and Solutions

==== Can't See JSON Files When Importing

**Problem**: File chooser only shows .json files, not all files

**Solution**:
Make sure the file chooser filter is set to "All Files (*.*)" or verify that your JSON file has the correct .json extension.


==== Projection Not Displaying

**Problem**: Content doesn't appear on the projection screen

**Steps to troubleshoot**:
1. Check that a projection screen is connected
2. Verify the projection view window is visible
3. Ensure a service item is selected
4. Click **Project** button
5. Check logs at `C:\Users\<username>\AppData\Local\PraiseView\praiseviewLog.log`

==== Phone Remote Not Connecting

**Problem**: Phone app cannot connect to the desktop

**Steps to troubleshoot**:
1. Verify both devices are on the same network
2. Check firewall settings - PraiseView needs port 8080 access
3. Restart the PraiseView application
4. Try connecting again with the provided address
5. Ensure phone and desktop are on the same WiFi network

==== Slow Performance

**Problem**: Application is running slowly or lagging

**Steps to improve performance**:
1. Close other applications running on the computer
2. Ensure you have at least 2GB of RAM available
3. Check disk space (at least 500MB free)
4. Reduce the number of videos in active service
5. Restart PraiseView and try again

==== Video/Audio Not Playing

**Problem**: Video or audio files won't play

**Solution**:
1. Verify file format is supported (MP4, WMV for video; MP3, WAV for audio)
2. Check that the file path hasn't changed
3. Try with a different file to isolate the issue
4. Update codec drivers on your system
5. Check logs for detailed error messages

==== Theme Settings Not Applying

**Problem**: Theme changes don't appear on projection

**Solution**:
1. Ensure you clicked **Save** after editing theme
2. Verify theme is selected in the Themes panel
3. Re-select the current item to refresh display
4. Restart PraiseView if changes still don't appear

==== Font Too Small/Large on Projection

**Problem**: Text is hard to read on projection screen

**Solution**:
1. Open Theme Editor
2. Adjust **Font Size** slider
3. Test with a sample verse before service
4. Consider room size and viewing distance
5. Use larger fonts for hymns, smaller for announcements

== Advanced Topics

=== Service File Management

Services are saved as `.service` files containing all items and their order for that service.

**Backing Up Services**:
1. Save services regularly using **File > Save Service**
2. Store backup copies on external drives or cloud storage
3. Create folders organized by month or season

**Sharing Services**:
Save and email `.service` files to team members or other churches.

=== Database Storage

All your content (songs, prayers, themes) is stored in a local SQLite database:
- Location: `C:\Users\<username>\AppData\Local\PraiseView\praiseview.db`
- Automatic backup: Create copies periodically
- No internet required: All data stays on your computer

=== Performance Optimization

**For Large Song Libraries**:
- Use category filters to reduce visible items
- Search by title for quick access
- Import songs in batches rather than all at once

**For Complex Services**:
- Limit the number of items in a single service
- Pre-load videos before service starts
- Test multimedia files beforehand

**For Older Computers**:
- Disable background videos in themes
- Use static image backgrounds instead
- Reduce font sizes and content per slide
- Close unnecessary applications
