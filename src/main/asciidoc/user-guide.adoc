== Introduction

This comprehensive guide covers all the essential features and workflows in PraiseView to help you manage and present content during worship services with confidence and ease.

image::../images/logo-transparent.png[PraiseView logo, align=center, width=220]

[NOTE]
This guide is organized by task. Use the table of contents on the left to navigate to the section you need.

== Interface Overview

[.ui-section]
*Main Application Layout*

The PraiseView interface is divided into four main areas:

image::../images/asidocs/interface-layout.jpg[Interface Layout, align=center]

- **Left Panel**: Service Order (Planner) - Your worship service sequence
- **Center Panel**: Stage View - Live preview of what's being projected
- **Right Panel**: Themes and Controls - Visual themes and display options
- **Bottom Panel**: Library Tabs - Access all your content (Songs, Prayers, Media, etc.)

== Creating a Service

=== New Service

To start a new service:

1. Click **File > New Service**
2. Clear the current service order and start fresh
3. Begin adding content from the library tabs

=== Save Service

Save your service for future use:

1. Click **File > Save Service**
2. Choose a location and filename
3. Your service will be saved in PraiseView format

To load a previously saved service, click **File > Load Service** and select the file.

== Managing Songs

=== Adding Songs

==== Add a New Song - Step-by-Step Wizard

The song editor now features a professional 4-step wizard interface for creating and editing songs.

===== Step 1: Basic Information

1. Go to the **Songs** tab at the bottom
2. Click **➕ Add New Song**
3. **Step 1: Basic Information** opens
4. Enter song details:
   - **Title**: Name of the song (required)
   - **Language**: Select from English, Latin, Hindi, Marathi, Konkani, Tamil, etc.
   - **Categories**: Select one or more categories (Entrance Hymn, Gloria, Responsorial Psalm, Communion, etc.)
5. Click **Next →**

===== Step 2: Verses

1. **Add verses** using the dropdown and text area
2. Select verse type:
   - **VERSE** - Standard verse
   - **CHORUS** - Repeating section
   - **BRIDGE** - Transition verse
   - **CODA** - Closing section
   - Custom labels (type your own)
3. Enter lyrics in the text area
4. Click **Add Verse** to add to the list
5. View all added verses in the "Added Verses" list
6. Review: When editing songs, you can:
   - Select existing verses to edit
   - Click **Edit Selected** to modify
   - Click **Delete Selected** to remove
7. Click **Next →**

===== Step 3: Performance Order

1. Arrange verses for display
2. **Available Verses** on left - all added verses
3. **Performance Order** on right - arrangement for projection
4. Use buttons to organize:
   - **→ Add to Order** - Add selected verse
   - **← Remove** - Remove from order
   - **↑ Move Up** - Reorder verses
   - **↓ Move Down** - Reorder verses
   - **Clear Order** - Start over
5. **Important**: You can add the same verse multiple times (e.g., Verse 1, Chorus, Verse 2, Chorus)
6. Drag and drop to reorder (drag within Performance Order list)
7. Click **Next →**

===== Step 4: Confirmation

1. Review the complete summary:
   - Title
   - Language
   - Categories
   - All verses with count
   - Performance order
2. Verify everything is correct
3. Click **← Previous** to go back and make changes, or
4. Click **Finish** to save the song

==== Import Songs

To import songs from a JSON file:

1. Click **File > Import Songs**
2. Select your JSON file
3. Songs will be added to your library automatically

=== Filtering Songs by Category

The Songs tab now includes a category filter on the left side:

1. Click a category name to show only songs in that category
2. Search by typing in the search field - it will search titles and categories
3. Click **Clear Filter** to show all songs again

=== Editing Songs

1. Select a song from the library
2. Click **✎ Edit Selected**
3. The song editor wizard opens with all existing data
4. Make changes using the same 4-step interface
5. Click **Finish** to save changes

== Managing Prayers

=== Adding Prayers

1. Go to the **Prayers** tab
2. Click **➕ Add New Prayer**
3. Enter prayer details:
   - **Title**: Name/subject of the prayer
   - **Content**: The full prayer text
4. **New Slide Button**: Use "+ New Slide" to split prayers into multiple slides
   - Click the button to insert `[==slide==]` marker at cursor position
   - During projection, content splits at markers into separate slides
   - Markers are hidden in projection (not visible to congregation)
5. Click **Save**

[EXAMPLE]
====
Adding slides to a prayer:

1. Type: "First part of prayer..."
2. Click "+ New Slide" button
3. Type: "Second part of prayer..."
4. Click "+ New Slide" button again
5. Type: "Final blessing..."

Result: When projected, appears as 3 separate slides that can be navigated.
====

=== Importing Prayers

1. Click **File > Import Prayers**
2. Select your JSON file (you can now see all files, not just .json)
3. Prayers will be added to your library

=== Using Prayers in Services

1. Drag prayers from the prayer library to the service order
2. Click to project a prayer
3. Use navigation buttons to go through content
4. If prayer has slide markers, navigate to different slides with **Next** button

== Service Order Management

The left panel shows your current **Service Order** - the sequence of items to present.

=== Adding Items to Service

Drag items from any library tab to the service order:

1. Click and hold on a song, prayer, or media item
2. Drag to the service order list
3. Release to place the item

=== Reordering Items

==== Using Buttons

1. Select an item in the service order
2. Click **▲ Up** or **▼ Down** to move it
3. Use multiple clicks to move items to the desired position

==== Using Keyboard

1. Select an item and press **Ctrl+Up** or **Ctrl+Down**

==== Using Drag & Drop

1. Click and drag an item within the service order list
2. Move it to the desired position

=== Deleting Items

1. Right-click an item in the service order
2. Click **Delete**
3. Or select an item and press **Delete**

== Projecting Content

=== Starting Projection

1. Select an item in the service order
2. Click **Project** button
3. Content appears on the projection screen

Or double-click an item to start from that point.

=== Projection Screen Status and Automatic Switching

The Stage View heading shows the current projection-screen status:

- **Green light**: A second display/projector is detected. PraiseView shows the live projection full-screen on that display.
- **Red light**: No second display is detected. The live projection is available in a separate window on the computer instead.

You can connect or disconnect a projector while PraiseView is open. When a projector becomes available, PraiseView automatically closes the windowed projection, opens it on the projector, and restores the current item and page. If the projector is disconnected, it returns the projection to windowed mode.

=== Navigation Controls

==== Verse/Page Navigation

- **Previous**: Go to previous verse or page
- **Next**: Go to next verse or page

==== Skipping verses
- Click on the verse number in the Current item Verses/Pages to skip to a specific verse.

==== Video Controls

- **⏪ -10s**: Rewind 10 seconds
- **⏯️ Play/Pause**: Toggle playback
- **⏩ +10s**: Forward 10 seconds

==== Screen Controls

- **Blackout**: Show black screen (with fade)
- **Clear**: Show logo or empty screen

=== Text Slides

Add custom text content for announcements, Scripture, or messages:

1. Go to **Text** tab
2. Click **➕ Add New Text**
3. Enter text details:
   - **Title**: Name/description of the text
   - **Content**: The full text content
4. **New Slide Button**: Use "+ New Slide" to split text into multiple slides

[EXAMPLE]
====
Creating a multi-slide announcement:

1. Type: "Welcome to our service..."
2. Click "+ New Slide" button
3. Type: "Today's reading from Scripture..."
4. Click "+ New Slide" button
5. Type: "Join us for coffee hour after service"

Result: Displays as 3 slides that can be navigated.
====

==== Using Text in Services

2. Click to project a text
3. Use navigation buttons to go through slides
4. If text has markers, each section displays on separate slide

== Themes

=== Applying Themes

1. Go to the **Themes** panel on the right
2. Use the theme dropdown to select a theme
3. The theme background applies to all projections instantly
4. Switch between themes anytime during service

=== Theme Options

- **Show Title on All Slides**: Show the title on every lyric slide
- **Show Title as First Slide**: Show the title only on the first slide
- These two options are mutually exclusive
- This setting is configured in **Themes > Theme Editor**

=== Creating Custom Themes - Step-by-Step Wizard

Click **+ Create New Theme** to open the theme editor with a professional 4-step wizard:

==== Step 1: Background Selection

1. **Choose background type**:
   - **Color**: Solid color background
   - **Image**: Static image background
   - **Video**: Animated video background (muted)
2. **Color selection**: Use color picker for solid colors
3. **File browser**: Select image or video files
4. Click **Next →**

==== Step 2: Main Text Settings

1. **Font family**: Choose typography style
2. **Font size**: Adjust text size (20px to 120px+)
3. **Text color**: Select color for lyrics/content
4. **Line spacing**: Control space between lines
5. **Additional styles**: Bold, italic options
6. Click **Next →**

==== Step 3: Title Settings

1. **Choose Title Display**: Select whether the title appears on all slides or only the first slide
2. **Title font**: Separate font for song/prayer titles
3. **Title size**: Larger size to distinguish from content
4. **Title color**: Separate color for titles
5. **Show title**: Toggle title display on/off
6. **Title alignment**: Left, center, or right
7. Click **Next →**

==== Step 4: Confirmation

1. **Full preview**: See complete theme with sample content
2. **Review all settings**:
   - Background (color/image/video)
   - Main text settings
   - Title settings
3. **Apply theme**: Click to save and apply
4. **Back navigation**: Click **← Previous** to return and adjust any step

=== Theme Selection Dropdown

- **Available themes**: All created themes appear in dropdown
- **Quick switching**: Select theme to apply instantly
- **Current theme**: Highlighted in the list
- **Reusable**: Use themes across multiple services

=== Edit Existing Themes

1. Select theme from dropdown
2. Click **Edit Theme**
3. Wizard opens with current settings
4. Make changes to any of the 4 steps
5. Click **Finish** to save changes

== Troubleshooting

=== Common Issues and Solutions

==== Can't See JSON Files When Importing

**Problem**: File chooser only shows .json files, not all files

**Solution**:
Make sure the file chooser filter is set to "All Files (*.*)" or verify that your JSON file has the correct .json extension.


==== Projection Not Displaying

**Problem**: Content doesn't appear on the projection screen

**Steps to troubleshoot**:
1. Check the status light beside **Stage View**. Green means a projector is detected; red means PraiseView is using windowed mode.
2. If the light is red, check the projector cable, power, and operating-system display settings. Set the display to **Extend**.
3. If the light is green, verify the projector is on the correct input and the projection is visible on the second display.
4. Ensure a service item is selected, then click **Project**.
5. Check logs at `C:\Users\<username>\AppData\Local\PraiseView\praiseviewLog.log`.

==== Phone Remote Not Connecting

**Problem**: Phone app cannot connect to the desktop

**Steps to troubleshoot**:
1. Verify both devices are on the same network
2. Check firewall settings - PraiseView needs port 8080 access
3. Restart the PraiseView application
4. Try connecting again with the provided address
5. Ensure phone and desktop are on the same WiFi network

==== Slow Performance

**Problem**: Application is running slowly or lagging

**Steps to improve performance**:
1. Close other applications running on the computer
2. Ensure you have at least 2GB of RAM available
3. Check disk space (at least 500MB free)
4. Reduce the number of videos in active service
5. Restart PraiseView and try again

==== Video/Audio Not Playing

**Problem**: Video or audio files won't play

**Solution**:
1. Verify file format is supported (MP4, WMV for video; MP3, WAV for audio)
2. Check that the file path hasn't changed
3. Try with a different file to isolate the issue
4. Update codec drivers on your system
5. Check logs for detailed error messages

==== Theme Settings Not Applying

**Problem**: Theme changes don't appear on projection

**Solution**:
1. Ensure you clicked **Save** after editing theme
2. Verify theme is selected in the Themes panel
3. Re-select the current item to refresh display
4. Restart PraiseView if changes still don't appear

==== Font Too Small/Large on Projection

**Problem**: Text is hard to read on projection screen

**Solution**:
1. Open Theme Editor
2. Adjust **Font Size** slider
3. Test with a sample verse before service
4. Consider room size and viewing distance
5. Use larger fonts for hymns, smaller for announcements

== Advanced Topics

=== Service File Management

Services are saved as `.service` files containing all items and their order for that service.

**Backing Up Services**:
1. Save services regularly using **File > Save Service**
2. Store backup copies on external drives or cloud storage
3. Create folders organized by month or season

**Sharing Services**:
Save and email `.service` files to team members or other churches.

=== Database Storage

All your content (songs, prayers, themes) is stored in a local SQLite database:
- Location: `C:\Users\<username>\AppData\Local\PraiseView\praiseview.db`
- Automatic backup: Create copies periodically
- No internet required: All data stays on your computer

=== Performance Optimization

**For Large Song Libraries**:
- Use category filters to reduce visible items
- Search by title for quick access
- Import songs in batches rather than all at once

**For Complex Services**:
- Limit the number of items in a single service
- Pre-load videos before service starts
- Test multimedia files beforehand

**For Older Computers**:
- Disable background videos in themes
- Use static image backgrounds instead
- Reduce font sizes and content per slide
- Close unnecessary applications
