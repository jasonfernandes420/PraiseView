== Overview

PraiseView is packed with powerful features to make managing day-to-day church presentations easy, professional, and reliable. This guide provides an in-depth look at each feature.

== 🎵 Songs and Music

=== Song Library

Store unlimited songs with complete information:
- **Title** - Song name
- **Category** - Genre, season, or custom grouping
- **Language** - For multilingual churches
- **Multiple Verses** - With custom labels (Verse, Chorus, Bridge, etc.)
- **Performance Order** - Arrange verses in display sequence
- **Search** - Find any song instantly by title or category

image::../images/asidocs/song-library.png[Song Library, align=center]

[NOTE]
Recommended: Organize songs into 5-10 main categories for optimal performance.

=== Category-Based Organization

Filter and find songs with powerful category system:
- **Filter by category** - Show only songs from selected categories
- **[All Songs]** option - View entire library
- **Combined with search** - Filter by both category AND text search
- **Custom categories** - Create categories that match your church's needs

image::../images/asidocs/category-filter.png[Category Filter, align=center]

=== Multiple Verses

Each song supports:
- **Unlimited verses** with custom labels
- **Verse 1, Verse 2** - Standard song structure
- **Chorus** - Repeating section
- **Bridge** - Transition verse
- **Coda** - Closing section
- **Custom labels** - Any text you want
- **Performance order** - Control which verses display during projection
- **Real-time navigation** - Skip to any verse with arrow keys or mouse click

== 🙏 Prayers and Scripture

=== Prayer Library

Manage prayers and readings with:
- **Quick access** - Find prayers instantly
- **Display during prayer times** - Project prayers for congregation to read
- **Share with congregation** - Make text visible to all attendees
- **Long-form support** - Prayers can be any length and automatically paginate
- **Reusable** - Save prayers to use in multiple services

=== Text Slides

Create custom text content for:
- **Announcements** - Important information
- **Scripture passages** - Bible verses or readings
- **Custom messages** - Welcome, benedictions, etc.
- **Welcome slides** - Greet attendees as they arrive
- **Call to action** - Event promotion and sign-up info

image::../images/asidocs/text-slides.png[Text Slides, align=center]

== 📸 Multimedia Support

=== Images

Display images during worship:
- **Format support** - JPG, PNG, GIF, BMP
- **Preview before projecting** - Verify image before showing
- **Full-screen projection** - Images scale to fill projection screen
- **Maintain aspect ratio** - Never distorted
- **Fade transitions** - Smooth appearance when switching images

=== Videos

Play videos in presentations:
- **Format support** - MP4, WMV, AVI, and other common formats
- **Built-in playback controls** - Play, pause, seek
- **Rewind/forward** - Jump 10 seconds forward or backward
- **Play/pause buttons** - Control from main interface
- **Audio** - Full sound with volume control
- **Automatic looping** - Option to repeat videos

image::../images/asidocs/video-player.png[Video Playback, align=center]

=== Audio

Add audio content for:
- **Background music** - During prayer or transition times
- **Special effects** - Audio for announcements
- **Song backing tracks** - Play music while congregation sings
- **Rewind/forward controls** - 10-second increment navigation
- **Play/pause** - Control from interface
- **Mute option** - Silent playback in preview

=== PowerPoint Integration

Display PowerPoint presentations:
- **Format support** - .ppt and .pptx files
- **Slide navigation** - Previous/Next buttons control slides
- **Auto-conversion** - Slides rendered as images for display
- **Seamless integration** - Blend with PraiseView content
- **Easy reordering** - Slides display in order

[CAUTION]
Large PowerPoint files may take time to load. Test before service.

== 🎨 Projection System

=== Live Preview

See exactly what will be projected:
- **Real-time mirroring** - Preview shows projection content
- **Stage view** - Center panel displays current content
- **Scroll text** - See how verses paginate
- **Test before projecting** - Verify everything looks correct

image::../images/asidocs/stage-view.png[Stage View Preview, align=center]

=== Projection Screen Control

Control what appears on the main display:
- **Project** - Show selected item
- **Blackout** - Black screen (for transitions, prayer)
- **Clear** - Logo/branding only
- **Fade transitions** - Smooth transitions between content

=== Display Modes

==== Show Title on All Slides

Display the song/prayer title on every lyric slide:
- Title appears at top of each verse
- Helps congregation follow along
- Consistent positioning throughout

==== Show Title as First Slide

Display title only on the first slide:
- First slide shows title only
- Subsequent slides show verses without title
- More minimal look
- Useful for familiar songs

[NOTE]
These two options are mutually exclusive. Choose one per theme.

=== Themes

==== Create Multiple Themes

Design custom visual themes:
- **Background colors** - Solid colors for clean look
- **Background images** - Seasonal or custom images
- **Background videos** - Dynamic visual elements (muted)
- **Color schemes** - Coordinated colors
- **Font customization** - Choose fonts and sizes
- **Text alignment** - Left, center, or right alignment
- **Title display** - Control title appearance

image::../images/asidocs/theme-editor.png[Theme Editor, align=center]

==== Theme Application

Themes appear behind all content:
- Songs and prayers
- Images
- Videos (background, not content videos)
- Text slides
- Announcements

==== Text Styling Options

Customize text appearance:
- **Font family** - Arial, Times New Roman, custom fonts
- **Font size** - 20px to 120px+
- **Text color** - Any RGB color
- **Line spacing** - Adjust space between lines
- **Text alignment** - Left, center, right
- **Background** - Solid color or image behind text

== 📋 Service Management

=== Service Planning

Plan your worship service:
- **Drag-and-drop** service organization
- **Easy reordering** - Move items up or down
- **Support all content** - Mix songs, prayers, media
- **Save for future** - Reuse services for future dates
- **Duplicate services** - Quick way to create similar services

image::../images/asidocs/service-planner.png[Service Planner, align=center]

=== Service Queue

The left panel shows your service order:
- **Double-click** to start from any item
- **Right-click** for context menu (delete, edit)
- **Keyboard shortcuts** - Move items with Ctrl+Up/Down
- **Automatic updates** - Projection updates when you change items
- **Current position** - Highlights the currently displayed item

=== Service Persistence

==== Save Services

Store services for reuse:

1. **File > Save Service** - Save current service
2. **Choose location** - Where to store the file
3. **.service file** - PraiseView's native format

==== Load Services

Reuse previously saved services:

1. **File > Load Service** - Open saved service
2. **Select file** - Choose .service file
3. **Items restored** - All items and order are loaded

## Advanced Service Features

- **Backup services** - Save copies to external drive
- **Share services** - Email .service files to team members
- **Version control** - Keep multiple versions (e.g., "Easter Service v1", "Easter Service v2")

== 📱 Phone Remote Control

=== Connect Your Mobile Device

Control presentations from your phone:
- **WebSocket-based** - Real-time connection
- **Same network** - Phone and desktop on same WiFi
- **Real-time sync** - Updates instantly
- **PraiseView Companion** - Download from Google Play Store

image::../images/asidocs/phone-remote.jpg[Phone Remote, align=center]

=== Phone Capabilities

From your phone, you can:
- **View service list** - See all upcoming items
- **Select songs** - Jump to any song in service
- **Navigate verses** - See all verses/pages
- **Select specific verses** - Display exact verse
- **Control playback** - Play/pause media
- **View live content** - See current verse

[TIP]
Keep phone on landscape orientation for better readability while controlling.

== 📤 Import/Export

=== Import Content

Add content from other sources:

==== Import Songs

**Format**: JSON with song data

Steps:
1. **File > Import Songs**
2. Select JSON file
3. Songs added to library
4. Duplicates automatically skipped

==== Import Prayers

**Format**: JSON with prayer data

Steps:
1. **File > Import Prayers**
2. Select JSON file
3. Prayers added to library

[NOTE]
Use "All Files (*.*)" filter if you can't see your JSON file.

=== Export Content

Share your content:

==== Export Songs

1. **File > Export Songs**
2. Select languages to export (or all)
3. Choose save location
4. **songs_export.json** created

==== Export Prayers

1. **File > Export Prayers**
2. Choose save location
3. **prayers_export.json** created

==== Export Services

Services are automatically saved as `.service` files containing:
- All items in service
- Item order
- Item details (songs, verses selected, etc.)

== Performance Tips

=== Optimize Performance

- **Limit items** - Keep service under 50 items for smooth operation
- **Image sizes** - Use 1920x1080 or smaller images
- **Video resolution** - Full HD (1080p) recommended
- **Frame rate** - 30fps or less for background videos
- **Regular backups** - Don't lose your content
- **Database maintenance** - Periodically backup your database
